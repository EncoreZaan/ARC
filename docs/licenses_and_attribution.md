Ce document certifie la conformité légale et le respect des droits d'auteur des composants utilisés dans le projet Revit AI Bridge.

---

## 1. Principes de Conformité Juridique
- **Aucune violation de propriété intellectuelle** : Aucun code propriétaire, binaire décompilé ou mécanisme sous licence restreinte (notamment de NonicaTab PRO ou de tiers) n'a été copié ou intégré dans ce projet.
- **Utilisation exclusive d'API officielles** : Toutes les interactions avec Revit reposent sur les interfaces publiques officielles fournies par Autodesk (`Autodesk.Revit.DB`, `Autodesk.Revit.UI`).
- **Respect des licences open source** : Tous les dépôts sources réutilisés ou consultés sont placés sous licence permissive MIT.
